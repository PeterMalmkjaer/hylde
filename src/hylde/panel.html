Hylde

Start serveren, læg nøglerne her, og lad Claude vælge en billig model til det nemme og en dyrere til det svære.

Stoppet

Claude

Nøgler

      
Tomt felt beholder den gemte nøgle. Hylde viser aldrig selve nøglen igen.


      

        
        
      

      
      
Haiku, Sonnet og Opus. Uden den kan de hylder ikke bruges.

      

      

        
        
      

      
      
nano og mini er de billige. GPT er den dyre.

Ollama

      
På maskinen, gratis. Kan køre samtidig med llama.cpp. Sig local til Claude, eller lad Hylde vælge.

      
      
      
      

        
        
      

      
      
Listen viser modellerne Ollama har hentet. Tomt felt bruger qwen2.5-coder:7b.

    


    

      
llama.cpp

      
Også på maskinen. Slå den til, hvis du vil bruge den samtidig med Ollama. Sig llama til Claude.

      
      
      
      
      

        
        
      

      
      
Listen hentes fra llama.cpp, hvis den kører. Ellers skriver du navnet selv.

    


    

      
Ollama Cloud

      
Ollama Cloud på ollama.com. Det er ikke Anthropic, og det kører ikke på maskinen. Det koster hos Ollama. Hylde vælger den ikke selv: sig cloud.

      

        
        
      

      
      
      
      

        
        
      

      
      
Listen hentes først, når nøglen er gemt. Hylde sender den ikke tilbage til siden.
